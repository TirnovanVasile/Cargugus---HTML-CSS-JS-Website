    DESPRE WEBSITE

Website de prezentare pentru Cargugus, o firma de logistica si curierat rapid.

    ROLUL PAGINILOR SECUNDARE

- ACASA: Prezentarea generala a firmei si a avantajelor.
- SERVICII: Afiseaza ofertele de curierat sub forma de carduri de servicii.
- PRETURI: Contine un calculator interactiv pentru estimarea tarifelor de expediere.
- CONTACT: Detalii de contact, program si adrese.

    IMPLEMENTARE JAVASCRIPT

- Generare continut dinamic: Pe pagina SERVICII, cardurile cu ofertele sunt generate dinamic dintr-un array JavaScript.
- Functie de calcul: Pe pagina PRETURI, functia calculeazaPret() calculeaza costul total al expeditiilor in functie de greutate si cantitate, incluzand o reducere de 10% pentru 3 sau mai multe colete.
